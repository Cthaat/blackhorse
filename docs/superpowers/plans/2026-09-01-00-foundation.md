# Laboratory Management Foundation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在批准的两个 RuoYi 快照上建立可登录、可鉴权、可从空库迁移、可测试和可生产构建的模块化单体底座。

**Architecture:** 后端保留 RuoYi 多模块结构并新增 ruoyi-lab；ruoyi-admin 只承载启动、全局配置和 lab Web Controller，业务规则进入 ruoyi-lab。MySQL 是业务事实源，Redis 不参与正确性判定。前端位于 ruoyi-ui，通过后端动态菜单装载业务页面。

**Tech Stack:** Java 17、Spring Boot 3.5.16、RuoYi-Vue 3.9.2、MyBatis-Plus 3.5.17、PageHelper 2.1.1、MySQL 8、Redis 7、Flyway 11.7.2、Springdoc 2.9.0、Knife4j 4.5.0、Vue 3.5.26、Vite 6.4.1、Element Plus 2.13.1、Pinia 3.0.4、Vitest 3.2.4、Node 22、Yarn 1.22.22。

## 需求与退出门禁

覆盖 FR-SYS-001、FR-SYS-002、FR-SYS-004、FR-SYS-006、FR-API-001 的基础能力，以及 AT-01、AT-02、AT-13、AT-15 的底座部分。

本计划结束时必须满足：

- 全新 MySQL 数据库通过 Flyway 建立 RuoYi、Quartz、字典、菜单和演示账号；
- 五类演示账号可登录，系统菜单权限符合角色矩阵；lab 业务子菜单和按钮由 V2_1 以后逐阶段加入；
- user_id=9000 的系统操作主体禁止登录且没有角色，`lab.system.operator-user-id` 精确引用该账号；
- 无权限接口返回 403，未登录接口返回 401；
- MyBatis-Plus BaseMapper 与 RuoYi PageHelper 可以同时工作，且只存在一套 MyBatis Spring Boot Starter；
- 非 prod 下 Knife4j 的 /doc.html 和 /v3/api-docs 可匿名读取，`/lab/**` 仍需 JWT；prod 下文档端点关闭；
- Maven Surefire 在 `clean verify` 中执行全部 `*Test` 与 `*IT`，前端单元测试和前端生产构建成功；
- 仓库中没有明文数据库密码、Redis 密码或 JWT 密钥。

- [ ] 3.8 创建 `assert-surefire-tests.ps1`，从 XML 报告证明每个必跑类被发现、至少执行一个测试且没有失败、错误或跳过；测试名和模块名先经白名单正则校验。

    param(
      [Parameter(Mandatory = $true)]
      [ValidatePattern('^[A-Za-z0-9_-]+$')]
      [string]$Module,
      [Parameter(Mandatory = $true)]
      [string]$RequiredTests
    )

    $ErrorActionPreference = 'Stop'
    $repoRoot = (Resolve-Path (Join-Path $PSScriptRoot '..')).Path
    $reportRoot = Join-Path $repoRoot "$Module\target\surefire-reports"
    if (-not (Test-Path -LiteralPath $reportRoot -PathType Container)) {
      throw "Surefire report directory not found: $reportRoot"
    }
    $testNames = $RequiredTests.Split(',', [System.StringSplitOptions]::RemoveEmptyEntries) |
      ForEach-Object { $_.Trim() }
    if ($testNames.Count -eq 0) {
      throw 'RequiredTests must contain at least one test class.'
    }
    foreach ($testName in $testNames) {
      if ($testName -notmatch '^[A-Za-z][A-Za-z0-9_]*$') {
        throw "Unsafe test class name: $testName"
      }
      $reports = @(Get-ChildItem -LiteralPath $reportRoot -Filter "TEST-*$testName.xml" -File)
      if ($reports.Count -ne 1) {
        throw "Expected one Surefire XML report for $testName, found $($reports.Count)."
      }
      [xml]$document = Get-Content -LiteralPath $reports[0].FullName -Raw
      $suite = $document.testsuite
      $tests = [int]$suite.tests
      $failures = [int]$suite.failures
      $errors = [int]$suite.errors
      $skipped = [int]$suite.skipped
      if ($tests -lt 1 -or $failures -ne 0 -or $errors -ne 0 -or $skipped -ne 0) {
        throw "Invalid Surefire result for ${testName}: tests=$tests failures=$failures errors=$errors skipped=$skipped"
      }
      Write-Host "VERIFIED TEST: $testName tests=$tests"
    }

`scripts/reset-test-db.ps1`：

    param(
      [Parameter(Mandatory = $true)]
      [ValidatePattern('^lab_test_[A-Za-z0-9_]+$')]
      [string]$DatabaseName
    )

    $ErrorActionPreference = 'Stop'
    if ($DatabaseName -notmatch '^lab_test_[A-Za-z0-9_]+$') {
      throw "拒绝重置不安全的数据库名: $DatabaseName"
    }
    $adminHost = $env:LAB_TEST_ADMIN_HOST
    $adminPortText = $env:LAB_TEST_ADMIN_PORT
    $adminUser = $env:LAB_TEST_ADMIN_USERNAME
    $adminPassword = $env:LAB_TEST_ADMIN_PASSWORD
    if ($adminHost -notin @('localhost', '127.0.0.1')) {
      throw "LAB_TEST_ADMIN_HOST 只允许 localhost 或 127.0.0.1，实际为: $adminHost"
    }
    $adminPort = 0
    if (-not [int]::TryParse($adminPortText, [ref]$adminPort) -or $adminPort -lt 1 -or $adminPort -gt 65535) {
