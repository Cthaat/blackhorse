# 现代实验室工作台：前端设计方案

## 目标与范围

在现有 Vue 3 / Element Plus 前端上改进可用性和视觉一致性，不替换业务架构，不引入新的 UI 框架。用户已选择浅灰底、白色工作区、深蓝导航和青绿色强调的“现代实验室工作台”方向。

本轮覆盖登录、应用导航、首页、实验室业务页面及共用表格、表单、分页、弹窗。保留全部现有功能和角色权限；小程序、AI、物联网、支付等分期需求不在本轮实现。只使用真实接口数据，不用假统计或无功能按钮装饰页面。

## 已观察到的问题

真实浏览器的预约审批页在 390 像素宽度下，日期范围筛选溢出，固定操作列遮住主要数据，面包屑与用户名拥挤。桌面页面缺少清晰的产品标识和统一的内容层级。基线截图保存在本地 output/playwright/before-desktop.png 和 before-mobile.png。

## 设计

### 1. 导航与视觉基础

- 深蓝侧栏使用清晰的实验室产品标识，选中态和分组层级明确；保留折叠及移动端抽屉。
- 浅灰画布、白色内容面板、青绿色主操作；错误、警告、成功保留语义色。统一字体、间距、边框、圆角和焦点样式。
- 顶栏中的菜单、消息、账户操作可键盘访问。窄屏简化面包屑、截断长用户名，不遮挡操作；保留现有主题和布局偏好。

### 2. 首页与功能发现

- 首页呈现真实待办、业务统计和可用功能入口，以操作优先而非装饰优先。
- 功能入口从已授权导航路由生成，保留路径和查询参数，不另建一套权限规则。
- 无实验室统计权限的角色显示其可用管理功能，不请求未授权统计接口，也不显示空泛欢迎页。

### 3. 业务页面与公共组件

- 统一页面标题、说明、筛选、工具栏、列表、分页和详情分区，使实验室、设备、资质、预约、使用、维修、巡检、隐患、消息等已有功能易于发现和操作。
- 筛选控件在窄屏适应容器；宽表格在内部横向滚动，移动端不让固定操作列覆盖数据。
- 分页随视口调整，换页滚动作用于实际内容区域。弹窗、抽屉、详情和上传区域适应小屏，保持按钮可触达。
- 数据加载、无数据、失败重试、输入校验反馈清楚；图标按钮具备可访问名称，禁止靠颜色单独表达状态。

### 4. 登录

- 使用与工作台一致的产品标识和轻量实验室主题图形，取代无关背景。
- 保留现有登录、验证码和安全策略；完善输入标签、自动填充、密码可见性和验证码失败反馈。

## 实现边界

优先抽取小型共用组件和样式，业务表单及权限逻辑留在原有页面。只修改与本轮体验直接相关的代码；不改数据库、不重置账户、不更改后端权限、不覆盖用户的 .vscode 配置。继续在项目根目录开发和版本管理，不使用 Docker 或额外工作树。

## 验证与完成口径

- 运行现有前端测试和生产构建；新增逻辑仅补必要的针对性测试。
- 使用真实浏览器检查全部实验室页面的入口和显示，并抽查管理员、学生、实验室管理员、安全员、维修员、系统管理员的授权界面。
- 在 320、390、768、1024、1440 像素宽度验证代表性页面，检查横向溢出、固定列、筛选器、弹窗、导航及键盘焦点。
- 保存前后截图，检查本轮操作的控制台及请求错误。发现问题修复后复验；未实际验证的路径明确列出，不承诺穷尽所有设备和条件下的零缺陷。
- 分批提交并推送经验证的改动，交付可运行页面和简短结果，不扩展成长篇测试或运维文档工程。

## 取舍

采用现代浅色工作台，兼顾高密度业务与清晰层级；不采用改动较小但识别度不足的传统后台样式，也不以全深色科技大屏为主界面。现有深色偏好仍应保持可读，独立大屏不在本轮范围内。
