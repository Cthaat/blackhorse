# 项目前期文档

本目录保存“高校实验室设备共享预约与安全巡检闭环管理系统”的V1需求、设计和策划基线。

建议按以下顺序审阅：

1. [软件需求规格说明书](requirements/lab-management-srs.md)
2. [总体设计说明书](superpowers/specs/2026-09-01-lab-management-design.md)
3. [项目策划书](planning/lab-management-project-charter.md)

当前状态：三份文档已完成内部一致性检查，等待用户书面审核。用户批准书面版本后，下一步才会形成逐任务实施计划；实施计划再次确认后才开始创建业务代码。

## 文档分工

| 文档 | 回答的问题 |
|---|---|
| 需求规格说明书 | 系统必须做什么，怎样判断完成 |
| 总体设计说明书 | 系统如何分层，数据和状态如何流转 |
| 项目策划书 | 六周内如何组织工作、验证质量和控制风险 |

## 已冻结的V1决策

- 项目方向：高校实验室设备共享预约与安全巡检；
- 周期：4～6周，以6周作为风险可控基线；
- 前端：单套响应式Vue 3 Web；
- 后端：RuoYi-Vue Spring Boot 3分支二次开发；
- 架构：前后端分离的模块化单体；
- 核心：预约使用闭环、维修验收闭环、巡检隐患闭环；
- 不包含：小程序、真实硬件、AI识别、复杂工作流和微服务。
